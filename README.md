# 会計アプリ

法人（まずは一般社団法人テクノケア、あとで株式会社も）の帳簿を付け、決算書と申告に写す数字を作るアプリ。
帳簿の正本は利用者の Google ドライブ（法人ごとのフォルダの 仕訳帳.csv など）。

- 設計書：docs/superpowers/specs/2026-10-05-accounting-app-design.md
- 段階1（土台）の計画：docs/superpowers/plans/2026-10-06-accounting-app-stage1.md
- 公開の手順：DEPLOY.md

## 段階
1. 土台（できている）：ログイン・法人・設定・勘定科目・仕訳の入力/修正/削除（変更履歴）・総勘定元帳・試算表・CSV の取り込み（領収書アプリ・書類アプリ・銀行）
2. 自動の取り込み：Stripe（決済・返金・手数料・振込）とサイト（内訳・講師報酬）
3. 期末と決算書：チェックリスト・仕訳案・共通の割り振り・締めと繰越・決算書類（PDF/CSV）
4. 申告と手続き：e-Tax・eLTAX に写す数字・手順書・届け出の期限・課税売上の監視
