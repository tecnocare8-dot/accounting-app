# 会計アプリ 段階1（土台）実装計画

- 設計書：docs/superpowers/specs/2026-10-05-accounting-app-design.md（8. 作る順番の「1. 土台」）
- 目的：ログイン → 法人を作る → 設定・勘定科目 → 仕訳の手入力・修正・削除（変更履歴つき）→ 総勘定元帳・試算表 → CSV の取り込み（領収書アプリ・書類アプリ・銀行）までを、本番で使える形で作る
- 仕組み：書類アプリ（~/.gemini/antigravity/playground/document-app）と同じ。Next.js 16 / next-auth（Google）/ Prisma＋PostgreSQL（Neon）/ Google ドライブ（drive.file）/ Vitest。ドライブまわり・CSV・暗号化・API の共通処理は書類アプリから写して使う
- 手元の確認：ポート 3200、DB は postgresql://localhost:5432/accounting_app_dev、擬似ドライブ DRIVE_FAKE_DIR=./fake-drive

| lib/fiscal.ts | 決算月から事業年度の範囲を出す・日付がどの年度か・締めた年度か |

| lib/records.ts | 仕訳帳.csv・勘定科目.csv・取り込み記録.csv の読み書き（1行＝仕訳の1行、同じ伝票IDで1取引） |
| lib/audit.ts | 変更履歴.csv（追記だけ） |
| lib/store.ts | 法人フォルダ内のファイルの読み書き（書類アプリの store と同じ考え方） |

## 決めたこと（設計書の細部）

- **伝票の行**：1行に借方・貸方の両方かどちらかを書く。伝票の区分（収益事業／非収益事業／共通）は伝票に1つ。保存の条件＝借方合計＝貸方合計、0円の行なし、金額は正の整数、科目が存在する、日付が締めた年度に入っていない
- **期首残高**：「期首残高」の伝票（非収益事業）を手で入れる。相手は繰越利益
- **試算表の繰越**：締め（段階3）の前でも正しく見えるよう、資産・負債・純資産は期間の終わりまでの累計、収入・支出は期間内、それより前の収入−支出は繰越利益に足して表示する
- **取り込みの二重防止**：取り込み元（receipts / document-payout / document-income / document-payment / bank:<口座科目>）＋取り込み元ID が同じ伝票が既にあれば候補に「取り込み済み」と出し、確定しても入れない
- **領収書アプリ**：分類→科目、支払い方法→貸方科目の対応表を設定に持つ（初期値：現金→現金、クレジットカード→未払金、それ以外→普通預金）。区分は科目の初期値
- **書類アプリ**：支払記録＝講師謝金（税抜＋消費税）／預り金（源泉）／普通預金（差引）、その他の入金＝普通預金・支払手数料／研修収入、入金記録（請求書の入金）＝普通預金・支払手数料／研修収入。取消のものは入れない
- **銀行**：CSV の列（日付・摘要・入金・出金、または金額±）を画面で選ぶ。相手科目は摘要の言葉で決める規則（設定）＋行ごとに画面で変えられる。決まらない行は「未確定」（仮払金・仮受金ではなく、取り込まずに残す）

## タスク

1. **土台**：package.json・設定ファイル・Prisma（User・Entity）・書類アプリから写す共通部品。`npm test` が通る
2. **科目・設定・年度**：lib/accounts.ts・settings.ts・fiscal.ts と テスト（決算月の変更、1年未満の年度、日付→年度）
3. **伝票と CSV**：lib/journal.ts・records.ts・audit.ts とテスト（検証、CSV の往復、Excel で保存し直した CSV）
4. **保存と帳簿の操作**：lib/store.ts・entity-store.ts・ledger.ts とテスト（追加・修正・削除・変更履歴・締めた年度・同時操作）
5. **集計**：lib/reports.ts とテスト（手計算の小さな例と一致、区分の絞り込み、前年度の損益の繰越）
6. **取り込み**：lib/importers/*・import.ts とテスト（各形式、二重取り込みなし、Shift_JIS）
7. **API**：認証・法人・設定・科目・仕訳・帳簿・取り込み・CSV の書き出し
8. **画面**：ホーム・仕訳（一覧・入力・修正）・帳簿（元帳・試算表）・取り込み・設定
9. **通しの確認**：擬似ドライブで、法人を作る→期首残高→手入力→取り込み→試算表 をヘッドレス Chrome で確かめる。DEPLOY.md（公開の手順）
