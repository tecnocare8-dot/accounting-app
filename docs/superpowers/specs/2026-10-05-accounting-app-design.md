# 会計アプリ 設計書

- 作成日：2026-10-05
- 状態：利用者と会話で合意済み（各節を1つずつ確認）。この文書の確認待ち
- 対象：一般社団法人テクノケア（非営利型）。あとで株式会社も入れられる作り

## 1. 目的と前提

### 利用者が言ったこと
- 非営利型の一般社団法人の会計を、**会計サービスも税理士も使わずに**、帳簿・決算書・申告まで自分たちで行いたい
- 一般社団法人の事業は**ウェブセミナーだけ**の予定。これまで売上はなく、申告はゼロで出していた
- 株式会社（介護事業など）も持っているが、今回の対象は一般社団法人だけ。あとから株式会社も入れられるようにする
- 決算月はあとで変えられるようにする
- 税務署へ相談に行くのは嫌ではない
- プレミアム会員はまだ始まっていない。銀行への入金もまだない

### 成功の条件
1. 1年分の取引が、Stripe・サイト・各アプリの CSV・手入力から、仕訳として漏れなく帳簿に入る
2. 期末の処理をチェックリストに沿って終えると、決算書類（全体と収益事業の分）が PDF と CSV で出る
3. 法人税（e-Tax）と地方税（eLTAX）の申告書に写す数字が、欄ごとに一覧で出る
4. 直した・消した記録が残り、締めた年度は変えられない

### このアプリが行わないこと
- 申告書の提出そのもの（e-Tax ソフト・eLTAX で利用者が行う）
- 収益事業にあたるかどうかの判断（税務署に確認した結果を設定に入れる）
- 消費税の申告（当面は免税事業者の前提。課税売上の監視だけ行う）
- 給与・社会保険の計算

## 2. 取引の取り込み元

お金の動きは **Stripe** を正とし、何の売上かは **サイト（thermal-photon の Firestore）** で補う。

| 記録 | 取り込み元 | 帳簿での扱い |
|---|---|---|
| 受講料・認定料・更新料・企業パッケージ・会員費の入金 | Stripe（決済。checkout の metadata に type・courseId・userId） | 売上。type で科目を分ける |
| 返金 | Stripe | 売上の取り消し |
| Stripe 手数料 | Stripe（決済ごとの実額。balance transaction の fee） | 支払手数料 |
| Stripe から銀行への振込 | Stripe（payout） | Stripe 残高 → 普通預金 |
| コース名・講師・企業名 | サイト（courses・users・packagePurchases など） | 売上の摘要・内訳、講師報酬の計算 |
| 講師への報酬 | サイトの報酬の計算（手取り基準）＋実際の支払い（書類アプリの支払記録 CSV） | 講師謝金・未払金・預り金（源泉） |
| そのほかの経費 | 領収書アプリの CSV、または手入力 | 経費 |
| 銀行の明細 | 銀行の CSV | 預金の照合（入出金の取り込みも可） |

- サイトだけでは漏れが出る（お金の記録が種類ごとに分散、プレミアム会員は金額を記録しない、返金・手数料・振込日が無い）ため、金額は必ず Stripe から取る
- 取り込みは何度実行しても二重にならない（取り込み元＋取り込み元のID で見分ける）
- Stripe は**読み取り専用の制限付きキー**、サイトは**読み取りだけの権限のサービスアカウント**を使う

## 3. 帳簿

### 決算書の形
一般社団法人に認められている**会社と同じ形**（貸借対照表・損益計算書）。公益法人会計基準の正味財産増減計算書は使わない。

### 勘定科目（初期値。追加・名前の変更ができる）
| 区分 | 科目 |
|---|---|
| 資産 | 普通預金、Stripe 残高、売掛金、前払費用 |
| 負債 | 未払金、預り金、前受金、未払法人税等 |
| 純資産 | 繰越利益 |
| 収入 | 受講料収入、認定料収入、更新料収入、研修収入、会費収入、寄付金収入、受取利息 |
| 支出 | 講師謝金、支払手数料、通信費、広告宣伝費、消耗品費、租税公課、法人税等、雑費 |

Stripe の type と科目の対応（初期値）：course_fee→受講料収入、certification_fee→認定料収入、renewal_fee→更新料収入、企業パッケージ→研修収入、premium_membership・company_membership→会費収入。

### 収益事業の区分
- 伝票（1つの取引）ごとに **収益事業／非収益事業／共通** のどれかを持つ。伝票の中の行はすべて同じ区分。こうすると損益だけでなく資産・負債も区分ごとに集計でき、収益事業の貸借対照表が作れる
- 区分のあいだでお金を動かすとき（非収益事業の預金から収益事業の経費を払ったなど）は、「区分間振替」の伝票で記録する
- 期首の残高（これまでの純資産）は非収益事業から始める
- 初期値は科目ごとに設定（受講料・認定料・更新料・研修収入＝収益事業、会費・寄付＝非収益事業、通信費などの共有経費＝共通）。**税務署に確認した結果に合わせて設定で変えられる**
- 「共通」は期末に割合で収益事業と非収益事業に分ける。割合の初期値は収入の割合、設定で変えられる

### 消費税
- 当面は免税事業者として**税込みのまま記録**
- 年度ごとの課税売上を集計し、1,000万円に近づいたら知らせる（基準期間＝2年前の年度で判定するため、前もってわかる）

## 4. 期末の処理と決算書

### 売上の計上時点
- オンライン受講料は**支払いを受けた時点**で売上
- 年度をまたいで提供する研修などは、必要に応じて前受金にできる（手で選ぶ）

### 期末のチェックリスト
| 順番 | 作業 | アプリがすること |
|---|---|---|
| 1 | 残高の照合 | 期末日の Stripe 残高・銀行残高と帳簿を比べ、差を示す |
| 2 | 講師報酬の未払い | サイトの報酬の計算から、期末までに確定し未払いの分の未払金の仕訳案 |
| 3 | 前受金 | 選んだ売上の前受金の仕訳案 |
| 4 | 前払費用 | 1年以内の分は支払時の経費のまま（短期前払費用の扱い）。それ以外だけ手で入れる |
| 5 | 固定資産 | 当面なし。10万円以上の物を買ったときに減価償却を足す（今回は作らない） |
| 6 | 共通の経費の割り振り | 割合で収益事業・非収益事業に分ける仕訳案 |
| 7 | 税金 | 均等割などを未払法人税等に計上する仕訳案 |
| 8 | 締め | 年度を締めて変更不可にし、期末残高を翌年度の期首に繰り越す |

仕訳案は利用者が確認して「確定」したときだけ帳簿に入る。

### 決算書類（PDF と CSV。ドライブに保存）
- 貸借対照表・損益計算書（法人全体）
- 収益事業の損益計算書と貸借対照表（法人税の申告に添付）
- 勘定科目の内訳書（預金・未払金などの内訳）
- 仕訳帳・総勘定元帳・試算表（保存用）

## 5. 申告に写す数字

- **国税（e-Tax ソフト）**：別表一・別表四・別表五（一）（二）などの欄ごとに、写す数字の一覧。添付する決算書類の PDF もここから出す。税額は e-Tax ソフトが計算するが、アプリでも同じ計算をして照らし合わせる
- **地方税（eLTAX）**：法人住民税・事業税の写す数字の一覧。収益事業がない年度の均等割の申告にも対応
- **手順書**：e-Tax・eLTAX での入力と提出の流れを画面順に説明するページ
- 申告の期限は決算日から2か月以内。ホームで知らせる

## 6. 手続きの一覧

期限つきの届け出をホームと「手続き」画面で知らせる。
- 収益事業開始届出書（収益事業を始めた日から2か月以内。税務署、県・市にも届け出あり）
- 青色申告の承認申請
- 毎年の申告の期限
- 内容は税務署で確認した結果に合わせて、利用者が完了の印を付ける

## 7. アプリの作り

### 技術
書類アプリ・領収書アプリと同じ：Next.js（Vercel）、Google ログイン、Neon（PostgreSQL）、Google ドライブ（drive.file の権限）。

### 保存場所
- **帳簿の正本は利用者の Google ドライブ**。法人ごとにフォルダ（例：「会計_一般社団法人テクノケア」）
  - `仕訳帳.csv`：1行＝仕訳の1行。1行に借方・貸方の両方（またはどちらか）を書き、同じ伝票IDの行で1つの取引にする。列：伝票ID、日付、行番号、借方科目、借方金額、貸方科目、貸方金額、区分（伝票で共通）、摘要、取引先、取り込み元、取り込み元ID、年度、作成日時、更新日時
  - `勘定科目.csv`、`設定.json`（法人名・決算月・区分の初期値・共通の割合・Stripe の type と科目の対応）
  - `変更履歴.csv`（直した・消した記録。追記だけ）
  - `取り込み記録.csv`（いつ・どこから・何件）
  - `決算/年度/*.pdf・*.csv`
- **Neon** には、利用者・法人の一覧・ドライブのフォルダID・**暗号化した Stripe キーとサイトのサービスアカウントの鍵**だけを置く（ドライブには置かない）
- 台帳の「読む→書く」は利用者・法人ごとにデータベースのロックで順番に行う（書類アプリと同じ）

### 画面
ホーム／取り込み／仕訳／帳簿（総勘定元帳・試算表）／期末／決算書／申告／手続き／設定（法人・決算月・勘定科目・区分の初期値・共通の割合・連携）

### 決算月
設定でいつでも変えられる。変えたときは、まだ締めていない年度の範囲だけが変わる（締めた年度は変えない）。決算月を変えると事業年度が1年未満になる年度ができるため、その年度は「変更後の初回の年度」として扱い、画面で範囲を確認してから保存する。

### 金額と計算
- 金額は1円単位の整数
- 仕訳は伝票ごとに借方合計＝貸方合計でないと保存できない

## 8. 作る順番

それぞれ作り終えるごとに使い始められる。

1. **土台**：ログイン・法人・設定・勘定科目・仕訳（手入力・修正・変更履歴）・帳簿（総勘定元帳・試算表）・CSV の取り込み（書類アプリ・領収書アプリ・銀行）
2. **自動の取り込み**：Stripe（決済・返金・手数料・振込）とサイト（内訳・講師報酬）
3. **期末と決算書**：チェックリスト・仕訳案・締めと繰越・決算書類
4. **申告と手続き**：写す数字の一覧・手順書・手続きの一覧・課税売上の監視

段階ごとに実装計画を作り、承認を受けてから作る。

## 9. 確かめ方

- 計算の部分（仕訳の検証、試算表・決算書の集計、区分と割り振り、締めと繰越、申告用の数字）は自動テストを先に書く
- 取り込みは、Stripe のテスト用データと、本番と同じ形の固定データで二重取り込みが起きないことを確かめる
- 画面はヘッドレス Chrome で、取り込み→仕訳→期末→決算書の流れを通しで確かめる
- 決算書の数字は、手で計算した小さな例と一致することを確かめる

## 10. 利用者に確かめてもらうこと（開発と並行）

- 税務署で：セミナー事業（受講料・認定料・更新料・企業パッケージ）が収益事業にあたるか、収益事業開始届出書・青色申告の承認申請の期限
- 決算月（あとで変えられるので、仮の値で始めてよい）
- Stripe の読み取り専用の制限付きキーの作成（手順は段階2で案内）
- サイト（Firebase プロジェクト terminal-photon-tecnocare）の読み取り専用のサービスアカウントの作成（手順は段階2で案内）
